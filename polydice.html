🎲 System Overview

PolyDice is a high-performance, 100% self-contained JavaScript 3D polyhedral dice simulation library. It requires zero external image files or 3D asset downloads—all 9 polyhedral meshes, UV projections, and high-resolution normal maps with engraved numerals are synthesized mathematically at runtime.

Key Architectural Pillars

  • Procedural Engraving & Normal Mapping: A dynamic 2048² canvas renders centered numeral glyphs and runs a Sobel edge-detection height-to-normal gradient shader to produce tactile, engraved depth.
  • Optional Procedural Beveling / Chamfers: Procedural geometric chamfer engine generating edge quad strips and vertex corner cap polygons directly in 3D (Off: 0.0, Subtle: 0.05, Round: 0.10). Exported .glb models need no vertex-merging when imported into Blender or game engines!
  • Ammo.js Rigid Body Dynamics: Continuous Collision Detection (CCD), restitution bounce, rolling friction, and realistic relative polyhedral mass ratios.
  • Synthesized Positional Audio: Momentum-attenuated Web Audio sound synthesizer with distinct wood/felt low-end thuds and crisp micro-detuned die clacks.
  • Headless Predetermined Roll Replay: Pre-simulates rolls in ~4ms headless Ammo.js steps, applies local face transformation offset qOffset, and replays with 100% authentic tumbling physics without mid-air steering.
  • Multi-Row Showcase & GLTF Export: Lineup view with upright face camera alignment, luminous silhouette outlines, and binary .glb 3D model export.

⚡ JavaScript Module & API Specification

PolyDice is structured as a standalone, zero-asset ES6 module (polydice.js) taking THREE and Ammo dependencies in its constructor, with backward-compatible aliases on window.

1. ES6 Module Import & Constructor

import { PolyDice } from './polydice.js'; // Host creates Three.js Scene, Camera, Renderer, and Animation Loop const dice = new PolyDice({ THREE, // Three.js library instance Ammo: window.Ammo, // Ammo.js WebAssembly loader or instance ConvexHull, // Optional: Three.js ConvexHull addon GLTFExporter, // Optional: Three.js GLTFExporter addon scene, // Host Scene (dice.group mounts automatically) tray: { width: 12.0, depth: 12.0, wallHeight: 2.4 }, audio: true // Web Audio collision synthesizer toggle }); // Initialize Ammo physics world await dice.init(); // In host render loop: function animate() { requestAnimationFrame(animate); const deltaTime = Math.min(clock.getDelta(), 0.05); dice.update(deltaTime); // Steps physics, syncs meshes, updates audio renderer.render(scene, camera); }

2. Core Instance Methods

// Roll active pool with Promise resolution: const result = await dice.roll({ power: 1.2 }); console.log('Result:', result.total, result.summary); // Roll guaranteed predetermined outcome: await dice.rollPredeterminedDice(['d20'], [20], 1.0); // Generate standalone die mesh (usable anywhere in your scene or pedestal): const dieMesh = dice.createDieMesh('d20', { bevel: 0.20, material: 'ruby' }); // Listen to roll events: dice.on('rollComplete', (result) => console.log('Settled:', result)); // Set bevel and material presets: dice.setBevel(0.20, 4); // ratio, segments (immediately updates settled dice) dice.setDiceMaterial('gold'); // updates all active dice immediately in real-time dice.setDieMaterial(specificDie, 'obsidian'); // changes material of an individual die! dice.selectDie(specificDie); // highlights die with cyan aura outline // Clean teardown & memory management: dice.dispose(); // frees GPU VRAM & Ammo WASM C++ heap memory

3. Backward-Compatible Window Aliases & Events

// Global convenience bindings (for webhooks & quick console tests): window.rollDicePool(power = 1.0, targets = null); window.rollPredeterminedDice(diceTypes, targetValues, power = 1.0); window.parseTargetRollString('2d6: 6, 6'); window.diceEngine; // Access the active PolyDice instance // Trigger roll via DOM Event (e.g. from server WebSocket): window.dispatchEvent(new CustomEvent('serverDiceRoll', { detail: '2d6: 6, 6' })); // Listen for finished roll: window.addEventListener('diceRollComplete', (e) => console.log('Event Result:', e.detail));
